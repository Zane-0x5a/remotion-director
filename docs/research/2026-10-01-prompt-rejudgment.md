# 全部提示词的第一性原理重判（票 14 第 2 步，2026-10-01）

> **状态：草案，待用户确认。** 确认后进入第 3 步：按结论重写提示词，跑测试。
>
> 起因：用户说"重要的不是捞不捞，而是第一性原理上怎样才是对的"。旧提示词里有些规则有道理，也没有随模型能力变化。但判断的标尺已经变了：判断时间的方式，从条带文件名上的 held/mid 标签变成了时间总览。所以规则不能原样抄回去，要从当前工具链出发重新定义。
>
> 已经定下的工具链（票 14 第 1 步）：评审材料是**时间总览 + 定态帧**；有 Bash 的评审可以拿时间总览当索引，从视频里抽任意时刻的原分辨率帧，或者做裁切；均匀静帧和条带都退出评审材料。状态术语（定态、过程态、定态里的抖动、短命内容）见 `CONTEXT.md`，四种都只是要看的现象。

## 0. 方法

每条规则问五件事：
1. 背后的原则是什么；
2. 它绑定在什么上；
3. 现在还成立吗；
4. 成立的话，用当前工具链怎么说；
5. 留、重写还是删。

"绑定在什么上"分四类：

| 记号 | 绑定 | 衰减 |
|---|---|---|
| **观** | 观看者的生理和心理：眼睛怎么看、读字要多久、注意力往哪走 | 不衰减 |
| **管** | 管线约定：谁看什么、谁判什么、交接和回报 | 随管线设计变 |
| **工** | 某个工具：条带、均匀静帧、文件名标签 | 工具一换就失效 |
| **旧** | 旧模型能力的短板，或旧语料里的翻车 | 随模型换代衰减，要用我们自己当前的运行重新取证 |

处理分四种：**留**（原样保留）、**改词**（原则不变，换成当前工具链的说法）、**重写**（原则成立，但原来的表述错了或过了头）、**删**。

现在的证据底子：
- **执行诊断**：N0 只做设计、施工和自检，不进批评环、不过节奏刀，6 支里 5 支质量 5、4 支成熟度 5。
- **消融**：无装备组的完成度最好。
- **成熟度研究**：最常见的成熟度缺陷在时间轴上，以前一直靠用户或节奏刀事后发现。
- **时间总览的自读核对和 T1**：时间总览读得准。描述员的标准和用户不同，那个描述员没带上套件里的规则。

## 1. 贯穿所有提示词的原则

逐条判断之后，留下来的规则都能归到下面七条原则里的某一条。归不进去的，就是该删或该重写的。

| # | 原则 | 类别 |
|---|---|---|
| P1 | **按第一次看片的人能看到、能看清、来得及看完的东西来判。** 构图类问题只在定态上判；过程态当运动来看；读字要有时间。没有放之四海皆准的版式模板，比如"结尾必须有定镜" | 观 |
| P2 | **不该知道意图的环节只看像素。** 时间总览是从像素算出来的，可以给盲的环节 | 管 |
| P3 | **现象归评审，机制和改法归施工者。** 评审报"看到了什么、多严重"，不开处方 | 管 |
| P4 | **评审意图的那只 agent 要有连续的上下文**：乙是同一个实例从头到尾 | 管 |
| P5 | **对用户的承诺不许悄悄改**：锁定的时长；用户只看视频；用户是最后一道关 | 管 |
| P6 | **读图模型看整帧时是降采样的，细节要裁到原分辨率看** | 观（模型的视觉条件） |
| P7 | **调过的措辞要靠"读原文"传下去，不靠转述** | 管 |

## 6. 节奏刀（`agents/tempo-pass.md`、`tempo.md`、create 的 Step 4.5）

**这一步存在的理由**，按它自己的原文是三条：
1. 批评环只判帧，条带在构造上就把时间轴压掉了，所以没有任何人在时间轴上看过这支片。
2. 环里那只乙的上下文被 N 轮局部修补占满，看不见整片的时间张弛。
3. 时间精确地写在源码里，新上下文读代码就能拿到完整数据。

**用现在的工具链重判**：
- 第 1 条**不再成立**。时间总览让甲和乙都看得到时间。
- 第 2 条部分成立。但甲不施工、没被修补腌过，现在又看得到整片的时间曲线，所以每一轮都能把时间判进去。
- 第 3 条对乙同样成立，乙手里就有源码。

**它当年的价值是真的**：V0、V9、V8 的停留问题都是它查出来的。但那是因为当时别的环节都看不到时间。自读核对里，V9 的小注停留和 V6 的黑场，在时间总览上都读得出来。

| 选项 | 内容 | 代价 |
|---|---|---|
| **A 并入（推荐）** | 撤掉单独的节奏刀。它判准里经得起第一性原理的部分，按 §7 的去向并进甲的时间判断和乙的自检。锁定时长的承诺（P5）转给乙和甲乙环遵守 | 少一次全新上下文的运行和收敛后的那次重渲。风险：甲乙环被修补占满时整片曲线被忽视。缓解：甲每轮都读时间总览 |
| B 保留，可选 | 默认不跑；甲乙环收敛后时间总览上还有明显的时间问题，才跑 | 多一个分支 |
| C 原样保留 | 只把它的材料换成时间总览 | 第 1 条理由已经不在了，它会和甲、乙重复判时间 |
